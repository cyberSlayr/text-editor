# Undo/Redo Text Editor

A simple console-based **Undo/Redo Text Editor** built using C++. This project demonstrates the practical implementation of the **Stack** data structure to manage text changes and restore previous or undone states.

## Features

* Add text
* Display current text
* Undo the last action
* Redo previously undone actions
* Clear all text
* Menu-driven interface

## Concepts Used

* C++
* Object-Oriented Programming
* STL Stack
* Strings
* Functions
* Stack-based state management

This project was built as a beginner-friendly implementation to understand how **Undo and Redo functionality works in real-world text editors**.
